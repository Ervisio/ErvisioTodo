Purpose: Carry the approved shell without repeating the design exploration. Rounds live in .variant-studio/rounds (gitignored).

## Structure (components/TodoApp.tsx -> .glass-shell grid; class names kept)
nav.rail (Rail.tsx, aria "Progetti": logo = Home, projects, Senza progetto, plus, settings link, account menu) | section.slab (aside.lists aria "Navigazione" + main.slab-main) | .detail-slot (TaskDetailPanel).
Lists column always open: smart views Oggi/Importanti (only when count > 0), hairline, project heading + "+" (Nuova lista), rows = outlined dot + name + count pill (zero shown).
Header: greeting (lib/i18n.ts greetingFor, set after mount to avoid hydration mismatch, username), h1 36px/700, then .head-end = ProgressRing (components/ui/ProgressRing.tsx, done = doneTaskCount, total = done + openTaskCount; hidden in smart views, cards view, Home, empty lists) + one "Altre azioni" menu (Vista | Lista | Progetto, danger last).
Rows (TaskItem): ring check, title 16px/500 single line, .row-chip after the title: due chip for ANY date (Oggi accent, overdue danger, Domani, weekday <= 6 days, else short date), "x/y" subtasks chip whenever subtasks exist (a button, aria "x/y sottoattività"), star (amber --star when set, hover otherwise). showExtras only adds list title, attachments, tags, assignees under the title.
Composer: outlined 54px pill after the last task; the completed line "N completate" (doneTaskCount) follows and expands completed rows in place; completing shows the "Completata / Annulla" toast.
Detail (TaskDetailPanel, 380px): outlined card, inline editing; header menu = Tutti i dettagli, Refactor AI (aiEnabled), Elimina.
Mobile (<= 760px): no bottom bar; the title is a button with a chevron (aria "Apri menu") opening the drawer (rail + lists, opaque, outlined); composer pinned at the bottom; unset stars hidden; detail = bottom sheet (opaque). Settings, search and account live in the drawer / "Altre azioni".
Tooltips: components/ui/TipLayer.tsx (data-tip, portal). Do not use title= with data-tip.

## Outline shell (approved 012-visual-black C, 2026-11-15)
Look: everything sits directly on the canvas (pure black in AMOLED/dark default). No panel fills, glass, blur, tint blobs or gradients; ShellBackdrop, --glass, --glass-hi, --tint-*, --glass-shadow and the mobile bar were deleted. Structure = hairlines (--hair, fg 9-10%), outlines (--edge, 16-18%), spacing. 24px-radius outlines only on composer, detail card, cards-view cards, settings sections, modals, menus.
Tokens (top of app/shell.css): --hair, --edge, --hover, --selected, --pop (opaque popup colour: canvas in dark, sheet in light), --star (#ffb020 dark / #c97a00 light). Menus, modals, toast, tooltip, mobile drawer/sheet use --pop + --edge, never translucency.
Rail: no background, dim tiles, only the selected tile (and Home when current) filled with --accent and --on-accent. Selected list row: 3px accent bar + weight 650, no fill (same bar in settings nav). Selected task row: 1px --edge, no fill. Menu checkbox items show one accent dot (no switch).
Accent: every accent element reads --accent / --accent-ink / --on-accent. lib/themes.ts onAccent() picks #000 or #fff by WCAG contrast (>= 4.5:1 for any accent), used by themeVariables and by surfaceStyle in TodoApp (list colours). --accent-ink falls back to the text colour when the accent is not readable on canvas and sheet. Buttons and switches are flat accent (gradients removed).
Traps: composer must keep no outline/border/shadow on focus (`.composer input:focus-visible` outline 0); other controls keep the global focus ring (detail note and .field inputs use accent border instead). Overlays need an opaque --pop. List colours stay an opt-in override via --list-bg on .task-surface. shell.css overrides globals.css; the settings area shares the rail and tokens (app/settings.css, app/auth.css restyled, 68px rail column in both).
Other traps: `.glass-shell > *` gets position: relative, so fixed children need `.glass-shell > .x`; `.task-row > .check-task` has margin -10px (detail checks must not); revalidate(except) avoids refetching a deleted task (404); "Prossima settimana" skips a Sunday-to-Monday duplicate of "Domani"; e2e rewrites docs/screenshots; Playwright isolated contexts hang after many opens, reuse the main page.
Invariants: no transform or animation on icons; allowed: opacity fades <= 150ms, the pulse of .task-loading; loading buttons stay static; lists API returns openTaskCount and doneTaskCount (top-level only); completed rows fetched only when expanded.
